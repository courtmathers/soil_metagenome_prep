# Soil metagenome workflow for MAG assembly and MicroTrait analysis

Repository containing workflow for:

- Adapter removal and trimming with Trim Galore
- Quality check with FASTQC
- Taxonomic classification from reads with Kraken2 and Braken
- Contig assembly with MEGAHIT
- Binning with MAXBIN2, METABAT2, CONCOCT, and optimization with DAS Tool
- MAG quality filtering with CheckM, and dereplication with dRep
