# Soil metagenome workflow for taxonomy and gene annotation

Repository containing comprehensive workflow including:

- Adapter removal, trimming, and quality check with Trim Galore / FASTQC
- Taxonomic classification from reads with Kraken2 / Braken
- Contig assembly with MEGAHIT
- KEGG Orthology gene annotation with Anvi'o
- KO ids -> trait abundances with rules form MicroTrait
